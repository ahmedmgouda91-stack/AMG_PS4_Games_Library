# AMG PS4 Games Library

مكتبة PS4 للموبايل: 632 عنوانًا، منها 36 إضافة جديدة، مع ملخصات عربية بدون حرق وأربع ثيمات: Crimson Dark وLight Crimson وMonochrome وPS4 White & Blue.

## الاستخدام

افتح `index.html` أو ملف HTML المنفصل مباشرة. البحث والفلاتر والاختيارات تعمل محليًا. روابط فيديوهات اللعب والمصادر تحتاج الإنترنت. احفظ نسخة اختياراتك من زر «تصدير اختياراتي» قبل تغيير المتصفح أو مسح بياناته. التخزين المحلي يعتمد على دعم المتصفح، خصوصًا عند فتح ملف مباشرة.

## GitHub Pages

1. ارفع محتويات هذه الحزمة في جذر مستودعك، بحيث يظهر `index.html` مباشرة.
2. من Settings → Pages اختر Deploy from a branch ثم main و/(root) ثم Save.
3. افتح الرابط الذي يظهر. تعمل المسارات أيضًا داخل مستودع فرعي. بعد أول تحميل كامل، يتيح Service Worker فتح المكتبة دون اتصال في المتصفحات الداعمة.

نشر GitHub Pages قد يجعل الصفحة ومحتوياتها متاحة للعامة؛ لم تُنشر هذه الحزمة أو تُرفع لأي مستودع. اختياراتك تبقى في متصفحك ولا تُضمّن في المستودع.

## البيانات

التقييمات إرشادية شخصية /10 وليست درجات Metacritic. المساحات تقريبية وتتغير بالتحديثات والإضافات؛ علامة «غير موثق» تعني أن المساحة لم تُثبت، ولا تُحسب في الإجمالي. سنة الإصدار تستهدف إصدار PS4. المجموعة الأصلية محفوظة، بما فيها أربعة عناوين تحتاج تحديد الإصدار/التحقق، وليست توصيات شراء مؤكدة. ملخصات الألعاب الرياضية تصف هدف اللعب. توجد مصادر وصور وروابط في تفاصيل البطاقات. بعض شعارات المجموعات تمثيلية ومعلّمة بذلك. الصور والشعارات ملك أصحابها، ولا تحتوي الحزمة ملفات ألعاب.

## English

Mobile-friendly, dependency-free PS4 catalogue with 632 entries, including 36 new games, Arabic spoiler-free premises, four themes (including PS4 White & Blue), search, filters, progress and a storage planner. Open index.html locally or upload this ZIP's root contents to a GitHub repository and enable Pages from main / root. Nothing has been published automatically. Hosted offline caching requires one successful initial visit; gameplay links require internet. Export selections before clearing browser storage. Ratings are personal guides, not aggregator scores; unknown sizes are excluded and explicitly counted. Four inherited unresolved entries remain labelled. Logos belong to their owners. No game binaries are included.
